# Testing Causality in Scientific Modelling Software

This is the replication package containing the code and data for the case studies in Section 5 of our paper entitled ["Testing Causality in Scientific Modelling Software"](https://doi.org/10.1145/3607184).
There is one subdirectory for each case study:
- Section 5.1 Poisson Line Tessellation Model (`poisson-process`)
- Section 5.2 Cardiac Action Potential Model (`LR91`)
- Section 5.4 Covasim: Observational Causal Testing (`covasim_case_study`)

See the README files in each subdirectory for details on each case study.
